# CommunityShield

A community-led public safety platform. Helps neighborhoods understand local crime patterns and direct prevention investment, outreach, and evidence-based programs where they will do the most good.

Initial city: Chicago. Schema is multi-city from day one.

## Stack

Backend: FastAPI, Python 3.12, PostgreSQL 16 + PostGIS, SQLAlchemy 2.0, Alembic, Pydantic v2.
ML: scikit-learn, XGBoost, LightGBM, SHAP.
Frontend: Vite, React, TypeScript, Tailwind v3, TanStack Query, Zustand, MapLibre GL JS, Recharts.
Infra: Docker Compose locally, Railway for production.

## Status

Phase 0: foundation in progress.
